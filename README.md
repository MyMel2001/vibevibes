# VibeVibes 🎧✨

> **Fully autonomous software ideation & synthesis.**  
> *Zero manual input. Low cost on architecture. High precision on code. Total flow on release.*

`VibeVibes` is a fully hands-off developer agent designed to autonomously invent, architect, implement, test, debug, and publish software tools to GitHub. By splitting responsibilities across models, VibeVibes uses a small model for ideation and architecture specifications, and a larger model for code generation, test execution, and self-healing debugging.

---

## 💡 The Fully Autonomous Pipeline

Running large models for entire coding tasks wastes context and tokens on brainstorming and structural setup. `VibeVibes` uses an **Ideator-Architect-Developer** flow to maximize speed, cost efficiency, and reliability:

```
               ┌───────────────────────────────────────────┐
               │     Phase 0: Ideator (Small Model)        │
               │  Invents high-value developer tool ideas  │
               └─────────────────────┬─────────────────────┘
                                     │
                                     ▼
               ┌───────────────────────────────────────────┐
               │    Phase 1: Architect (Small Model)       │
               │   Generates detailed SPEC.md blueprint    │
               └─────────────────────┬─────────────────────┘
                                     │
                                     ▼
               ┌───────────────────────────────────────────┐
               │    Phase 2: Scaffolding (Large Model)     │
               │  Generates complete code & test suites    │
               └─────────────────────┬─────────────────────┘
                                     │
                                     ▼
               ┌───────────────────────────────────────────┐
               │ Phase 3 & 4: Execution & Self-Healing     │
               │    Runs `npm test` local test suite       │
               └─────────────────────┬─────────────────────┘
                                     │
                      ┌──────────────┴──────────────┐
                   PASSED                         FAILED
                      │                             │
                      ▼                             ▼
              Publish to GitHub            Auto-Repair Loop
             (Repo & Release)             (Up to 5 attempts)
```

1. **Phase 0: Ideation (Small Model)** — Autonomously conceives useful utility tools, CLI apps, or libraries designed for automated testability.
2. **Phase 1: Architecture (Small Model)** — Converts the selected idea into a minimal `SPEC.md` detailing the file tree, API contracts, and testing strategy.
3. **Phase 2: Scaffolding (Large Model)** — Reads `SPEC.md` and generates all required source files and unit tests.
4. **Phase 3: Automated Test Execution** — Runs `npm test` locally.
5. **Phase 4: Self-Healing Debug Loop (Large Model)** — If tests fail, stderr output and workspace state are sent back to the coding model to fix errors automatically.
6. **Phase 5: Automated Release** — Initializes Git, pushes to a public GitHub repository, and creates a tagged `v1.0.0` release using the `gh` CLI.

## 🚀 Quick Start

### Prerequisites

* **Node.js**: `v20.6.0+` (for native `--env-file` support).
* **GitHub CLI (`gh`)**: Installed and authenticated (`gh auth login`).
* **Model Engine**: Any OpenAI-compatible server or local engine (Ollama, vLLM, OpenRouter, OpenAI, etc.).

### Installation

```bash
# Clone repository
git clone https://github.com/your-username/VibeVibes.git
cd VibeVibes

# Install dependencies
npm install
```

---

## ⚙️ Configuration (`.env`)

Create a `.env` file in the root directory:

```env
# Planner & Ideator Model (Small & Fast)
PLANNER_BASE_URL="http://localhost:11434/v1"
PLANNER_API_KEY="ollama"
PLANNER_MODEL="qwen2.5-coder:7b"

# Coder & Debugger Model (Large & Precise)
CODER_BASE_URL="https://api.openai.com/v1"
CODER_API_KEY="sk-proj-..."
CODER_MODEL="gpt-4o"
```

---

## 🛠️️ Usage

Launch VibeVibes without any arguments. The agent handles ideation, execution, and deployment automatically:

```bash
npm start
```
